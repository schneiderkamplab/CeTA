TRS_Spec_Base.thy
-----------------
- type ranked_signature
  Change to
    "'f \<Rightarrow> nat"
  Argument: if we have a type S, we can always make the subtype {x:S | f x = Some n}. So all results still hold.
  Also, shouldn't this be called "arity"? It _is_ the arity function...

- there should be a type definition "'f 'v rewriting_rules" for
    "'f 'v ((('f,'v) fo_term \<times> ('f,'v) fo_term) set)"
  (a set of rewriting rules). This is done for conditional and equational rewriting systems

- definition trs_problem
  Remove first conjunct:
    infinite (UNIV :: 'v set)
  The infinity of a set of variables should be a separate hypothesis, and assumed when needed. I am also not sure about this formulation (why add UNIV?).
