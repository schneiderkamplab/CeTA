Certification Problem

Input

We consider the TRS containing the following rules:

I(x) → I(J(x)) (1)
J(x) → J(K(J(x))) (2)
H(I(x)) → K(J(x)) (3)
J(x) → K(J(x)) (4)

The underlying signature is as follows:

{I/1, J/1, K/1, H/1}

Property / Task

Prove or disprove confluence.

Answer / Result

Yes.

Proof (by ttt2)

1 Rule Labeling

Confluence is proven, because all critical peaks can be joined decreasingly using the following rule labeling function (rules that are not shown have label 0).
  • I(x) → I(J(x)) (1)
    ↦ 1
  • J(x) → J(K(J(x))) (2)
    ↦ 0
  • H(I(x)) → K(J(x)) (3)
    ↦ 0
  • J(x) → K(J(x)) (4)
    ↦ 0
The critical pairs can be joined as follows. Here, ↔ is always chosen as an appropriate rewrite relation which is automatically inferred by the certifier.
  • The critical peak s = H(I(J(x)))←→ε K(J(x)) = t can be joined as follows.
    s ↔ K(J(J(x))) ↔ K(J(K(J(x)))) ↔ t
  • The critical peak s = H(I(J(x)))←→ε K(J(x)) = t can be joined as follows.
    s ↔ H(I(K(J(x)))) ↔ K(J(K(J(x)))) ↔ t
  • The critical peak s = J(K(J(x)))←→ε K(J(x)) = t can be joined as follows.
    s ↔ K(J(K(J(x)))) ↔ t
  • The critical peak s = K(J(x))←→ε J(K(J(x))) = t can be joined as follows.
    s ↔ K(J(K(J(x)))) ↔ t
